# ITR Photography — Business & Workflows

Isaac Rodriguez / ITR Photography. Documentary and street photographer based in Southern California.

> "I photograph life as I love it and live it — from the streets of LA to labor rallies to everywhere I find myself paying attention."

This repository is the operational system for ITR Photography: business rules, pricing logic, workflows, open decisions, and eventually contract templates. It is structured so both Isaac and AI agents can use it to run and grow the practice.

---

## What's here

### `constitution/business-constitution.md`
The single source of truth. Pricing, licensing framework, contract principles, definitions. Start here. Written June 3, 2026.

### `strategy/audience-and-sustainability.md`
The strategic layer — audience-building orientation, theory of discovery (Instagram vs. portfolio site), the two-audience model (professional vs. community), the editorial/press path for documentary photographers, sustainability framework, and the guiding question about the role of photography in Isaac's life. Read this before making investment decisions.

### `workflows/`
Step-by-step operational guides:

| File | Covers |
|------|--------|
| `01-client-intake.md` | First contact → qualification → proposal → booking |
| `02-pre-production.md` | Track B only: creative brief → scout → shot list → logistics |
| `03-shoot-day.md` | Equipment checklist → arrival → shooting → wrap |
| `04-post-production.md` | Backup → cull → edit → deliver → revisions |
| `05-invoicing.md` | Pricing quick-reference and invoice math |

### `open-questions.md`
23 unresolved decisions — from Adobe subscription tier to contract clause language to community rate criteria to the role of photography in Isaac's life. Check these off as decisions are made.

### `templates/`
Stub for contract templates, creative briefs, and proposal formats. To be built as open questions Q6–Q14 are resolved.

### `CLAUDE.md`
Instructions for AI agents working in this repo. References the constitution as the authoritative source.
